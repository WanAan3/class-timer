时钟 & 桌面倒计时 · 使用说明
=============================

一、程序组成（都在本文件夹）
    启动北京时间.bat        打开白色大时钟窗口（时钟 / 倒计时 / 设置，单窗口）
    启动桌面倒计时.bat      打开桌面上的蓝色中考倒计时挂件
    beijing_time.pyw       主程序：时钟、倒计时、设置页
    desktop_countdown.pyw  桌面倒计时挂件
    alarm.wav             倒计时结束的闹钟铃声（可自行替换同名文件）
    countdown_settings.json    设置（主题、挂件日期/名称/颜色/大小/位置）
    北京时间.html           网页版时钟（备用）

二、浅色 / 深色模式（入口在菜单里）
    左侧菜单滑出后，左下角「设置」上方是「深色模式」一行，只有一个太阳 / 月亮图标
    （没有开关按钮，点图标或整行就切换，图标随状态变化）。
      切换过程：背景、文字、图标颜色一起平滑过渡（约 0.25 秒），
      文字和图标全程可见，不会被遮罩盖住，也不是整屏白 / 黑画面切换。
      浅色：白底黑字，菜单也是浅色（#f5f6f8），蓝色高亮条
      深色：背景 #232733、侧栏 #1d2027、卡片 #2e3240（取自参考图），文字变白
    时钟、倒计时、设置页、左侧菜单四处一起切换，配色统一；
    选择会写进 countdown_settings.json 的 theme 字段，下次启动自动沿用。

三、菜单行为
    左上角三条横线滑出菜单后：
      · 点「时钟」「倒计时」「设置」切换页面时，菜单保持展开，只有页面在换
      · 点菜单外空白处、再点一下菜单键、或按 Esc，菜单才向左滑回收起
      · 当前项左侧的蓝色选中条会在选项之间上下滑动（0.17 秒），
        从「时钟」滑到「倒计时」、一直滑到左下角「设置」，不会消失

四、动效
    主题切换      配色交叉渐变（约 0.25 秒），文字图标全程可见
    开关          小白点向右 / 向左滑动（约 0.2 秒，缓出），不是瞬间跳变
    卡片大小      蓝色选中块在小 / 标准 / 大 / 特大之间滑动（约 0.17 秒）
    菜单选中条    蓝色竖条随选中项上下滑动，包含底部「设置」
    菜单          从左侧滑入滑出（约 0.19 秒）
    换页          时钟 ↔ 倒计时 淡出→淡入（深浅色下都朝当前背景色淡出）

五、设置页（单窗口，不另开窗口）
    入口：菜单左下角齿轮；桌面挂件的齿轮（打开主程序并停在设置页）
      桌面倒计时   开关，启动或关闭桌面挂件
      开机自启动   开关，登录 Windows 后自动打开桌面挂件
                   （写在 HKCU\\Software\\Microsoft\\Windows\\CurrentVersion\\Run，
                    不需要管理员权限；关掉即删除该项）
      卡片颜色     6 个预设色 +「自定义…」取色器
      卡片大小     小 / 标准 / 大 / 特大
      倒计日名称   卡片上方标题
      倒计时日期   日期 + 时间，如 2027-06-15 09:00
      下方文字     卡片底部小字
      免责声明     「查看声明」按钮，弹窗显示完整条款（个人制作、仅供班级使用、请勿商用）
    所有改动即时保存，正在运行的挂件约 0.6 秒内自动刷新。

    免责声明要点：本程序为个人业余制作，仅供本人和班级同学/老师免费使用；
    禁止任何商业用途（出售、出租、捆绑、付费服务等）；程序按“现状”提供，
    计时误差、提醒未响等不作担保，重要考试时间以学校通知为准；
    程序不联网、数据只存本机；第三方名称/图标归其所有者。

六、桌面倒计时挂件
    拖动        按住左上角六个点（或卡片任意位置）拖动，松手记住位置
    齿轮        打开主程序的设置页
    添加倒计时  打开主程序并停在倒计时页
    右键菜单    设置 / 打开倒计时程序 / 窗口置顶 / 退出

七、时钟主程序
    时钟页        超大号北京时间 + 日期星期，字号随窗口缩放
    倒计时        时 : 分 : 秒 三段大数字，每段上下方都有箭头（▲/▼）加减，
                  蓝色横线下方是「开始 / 重置」；按钮下面还有 50 / 100 / 120 分钟
                  快捷键（120 分钟即 02:00:00），点一下直接设好时长；
                  运行时箭头锁定、数字倒数；
                  重置：停止计时并回到开始前设定的时长（没开始过则回到默认 00:05:00）；
                  归零后循环播放 alarm.wav，数字蓝色闪烁，
                  窗口底部弹出「⏰ 时间到 / 停止」，点停止、重新开始或重置即关掉铃声
    快捷键        Esc 关菜单 / 从设置页返回 / 退出；F11 全屏

八、说明
    · 时间固定取 Asia/Shanghai（UTC+8），与电脑本地时区无关
    · 纯 Python 3 自带 tkinter 实现，不联网、不写注册表
    · 动画速度：beijing_time.pyw 顶部 SLIDE_MS、SLIDE_FRAMES、FADE_OUT_MS / FADE_IN_MS；
      主题渐变的步进在 App._animate_theme_change 里（steps / 18ms）
    · 配色：beijing_time.pyw 里的 THEMES 字典，想微调深浅两套颜色改这里即可

九、网页版（备用）
    双击「北京时间.html」，浏览器里同样是白底黑字的大号北京时间，F11 可全屏。
